# E-Commerce Customer & Sales Analysis | Power BI

An interactive Power BI dashboard that turns raw e-commerce transaction data into insights about business performance, customer purchasing behavior, and
customer value.

## Project Objective
To understand how the business is performing, how customers purchase, and which customers are the most valuable, using exploratory analysis and
customer segmentation.

## What the Dashboard Covers

**1. Exploratory Data Analysis (EDA)**
Sales performance across products, countries, and time periods.

**2. Customer & Transaction Frequency Analysis**
How often customers purchase and how that relates to revenue and
average purchase value.

**3. RFM Customer Segmentation**
Customers grouped by Recency, Frequency, and Monetary value into
High Value, Medium Value, Low Value, and Dormant segments.

## Tools & Techniques
- Power BI
- DAX
- Power Query
- Data Visualization
- RFM Analysis
- Exploratory Data Analysis
